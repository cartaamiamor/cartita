# AGENTS.md — Sitio “Primer mes con Sofía”

## Objetivo
Mantén este sitio como una experiencia romántica, cálida, elegante y personal para celebrar el primer mes con Sofía el 23 de agosto de 2026.

## Dirección visual
- Tema: cuento nocturno moderno, luna, flores, papel de carta, tonos lavanda/rosa/dorado.
- Evita que parezca una landing page de SaaS, un dashboard o una plantilla genérica.
- Prioriza emoción, tipografía, espacio, ritmo visual y microinteracciones suaves.
- Mantén el contenido apto para compartir con familia/amigos: romántico, no sexualizado.
- No uses personajes, logos ni ilustraciones protegidas de Disney; si quieres evocar ese gusto, usa una estética original de cuento/fantasía.

## Contenido que debe conservarse
Sofía:
- estudia psicología;
- es buena en su trabajo;
- le gusta el cine;
- le gustan las crepes;
- tiene una perrita;
- le gusta mirar la luna;
- es dormilona;
- le gustan los tallarines rojos con pollo;
- le gustan las flores;
- tiene un lado juguetón y tierno con su pareja;
- hace entrenamiento funcional;
- aniversario de primer mes: 23 de agosto de 2026.

## Restricciones técnicas
- Debe funcionar en GitHub Pages como sitio estático.
- `index.html` debe seguir siendo suficiente para ejecutar el sitio; no introducir backend.
- No exigir npm/build si la mejora puede resolverse con HTML/CSS/JS nativo.
- Usar rutas relativas para assets (`assets/...`).
- Responsive desde 360 px hasta escritorio ancho.
- Mantener accesibilidad: contraste razonable, focus visible, labels/ARIA cuando corresponda y `prefers-reduced-motion`.
- No autoplay de audio/video.
- Evitar librerías pesadas para efectos simples.

## Proceso de mejora
1. Inspecciona primero todo `index.html` y este archivo.
2. Identifica los 3 cambios con mayor impacto visual/emocional.
3. Implementa cambios de forma coherente con el sistema visual existente.
4. Valida mobile, tablet y desktop.
5. Revisa que no haya overflow horizontal, texto cortado, imágenes deformadas o botones inaccesibles.
6. Mantén la página rápida y fácil de subir a GitHub Pages.
7. Si agregas fotos, usa nombres claros dentro de `assets/` y conserva fallback si faltan.

## Barra de calidad
Antes de terminar una mejora, pregunta internamente:
- ¿Se siente hecha específicamente para Sofía?
- ¿El primer viewport emociona sin estar sobrecargado?
- ¿Cada sección tiene una razón de existir?
- ¿La experiencia móvil se siente diseñada y no solo encogida?
- ¿Las animaciones aportan ternura y no distraen?
