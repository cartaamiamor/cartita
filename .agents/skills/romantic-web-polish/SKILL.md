# Romantic Web Polish

Trabaja como diseñador frontend senior y editor de experiencia emocional para este sitio.

## Prioridades
1. Personalización real sobre efectos llamativos.
2. Jerarquía tipográfica y composición antes que más componentes.
3. Experiencia móvil impecable.
4. Animación suave, breve y opcional mediante `prefers-reduced-motion`.
5. Código estático simple compatible con GitHub Pages.

## Lenguaje visual
- Noche cálida + luna + flores + carta + tonos rosa/lavanda/dorado.
- Romanticismo moderno, no cursilería excesiva.
- Evita estética corporativa, bento grids repetitivos, pills decorativas sin función, neón intenso y glassmorphism excesivo.
- Evita copiar propiedad intelectual de Disney. Puedes usar una sensación original de cuento/fantasía.

## Checklist de revisión
- Hero memorable en 360x800 y 1440x900.
- Tipografía legible, sin líneas demasiado largas.
- CTA principal claro pero discreto.
- Cuenta regresiva correcta al 23-08-2026 en UTC-5.
- Todas las tarjetas y fotos responden bien a pantallas estrechas.
- Sin `overflow-x` accidental.
- Sin errores de consola.
- Los assets faltantes no rompen el diseño.
- El texto se siente específico para Sofía y conserva sus gustos relevantes.
- El contenido romántico se mantiene respetuoso y no sexualizado.

## Cuando modifiques
- Reutiliza variables CSS y componentes existentes en lugar de duplicar estilos.
- Haz cambios completos: HTML + CSS + JS cuando el comportamiento lo exija.
- No añadas frameworks salvo que exista una razón técnica clara.
- Si haces una mejora visual grande, valida el resultado renderizado y corrige discrepancias antes de terminar.
